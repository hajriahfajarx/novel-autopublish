2. Hubungkan Google Account (Blogger + Sheets)

Dari Google Cloud Console → APIs & Services → Credentials → OAuth client ID (tipe: Desktop app), pakai akun Google yang baru.

4. Jadwal terbit

1 bab/hari, menargetkan terbit sekitar jam 22:00–23:30 WIB (jadwal cron digeser lebih awal untuk kompensasi keterlambatan GitHub Actions). Untuk mengubah jam/frekuensi, edit .github/workflows/daily-post.yml dan scripts/check-slot.mjs bersamaan (lihat README).
